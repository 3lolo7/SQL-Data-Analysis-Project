# MySQL Sales Data Analysis

## Project Overview

This project focuses on querying and analyzing sales and product data using MySQL. It demonstrates fundamental SQL skills for retrieving, filtering, sorting, grouping, and summarizing data.

## Technologies Used

* MySQL
* SQL

## SQL Concepts Covered

* **SELECT** — Retrieve data from database tables.
* **WHERE** — Filter records based on specified conditions.
* **ORDER BY** — Sort query results.
* **GROUP BY** — Group records based on shared values.
* **HAVING** — Filter grouped results using conditions.
* **Aggregate Functions** — Summarize data using functions such as `COUNT()`, `SUM()`, `AVG()`, `MIN()`, and `MAX()`, where applicable in the queries.

## Dataset Domain

Sales and Products

## Project Objectives

* Retrieve relevant information from sales and product data.
* Filter records using specific conditions.
* Sort query results for easier interpretation.
* Group data to summarize information by selected categories.
* Apply aggregate functions to calculate summary statistics.
* Use `HAVING` to filter aggregated results.

## How to Use

1. Install MySQL Server and a MySQL client, such as MySQL Workbench.
2. Set up the database and tables used by the project.
3. Open the SQL query file.
4. Execute the queries against the corresponding database.

The original dataset and database schema should be provided separately if they are available and can be shared.
